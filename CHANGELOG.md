# Changelog

## v1.2.0 - 2026-11-18
### Cambiado
- Las operaciones se extrajeron a métodos: sumar, restar, multiplicar y dividir.
- La excepción de división entre cero se lanza dentro del método dividir.
- El comportamiento del programa no cambia.

## v1.1.0 - 17-11-2026
### Agregado
- Manejo de excepciones con try-catch para entradas inválidas.
- Control de la división entre cero.

### Cambiado
- El programa ya no se cierra ante un error: avisa y vuelve al menú.

Todos los cambios importantes del proyecto se documentan en este archivo.

## v1.0.0 - 16-11-2026
### Agregado
- Calculadora de consola con suma, resta, multiplicación y división.
- Menú interactivo con opción de salir.
